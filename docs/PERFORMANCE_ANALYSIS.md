## 五、策略组合建议

### 推荐组合 (多策略分散)

```
50% MACD信号 (高Sharpe, 趋势主力)
30% 双均线   (低换手, 稳定性补充)
20% 配对交易 (低回撤, 对冲保护)
```

**预期组合特征**: 
- 收益: 150-200%
- 最大回撤: 15-20% (分散后低于单独使用)
- Sharpe: 1.0-1.5

### 需要回避

- **RSI单独使用**: 牛市环境下确定性负收益
- **布林带高频版**: 5000+信号/年，交易成本侵蚀严重
